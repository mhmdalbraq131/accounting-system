# قواعد المحاسبة

## القيد المزدوج

كل قيد يجب أن يحتوي على سطرين أو أكثر، ومجموع المدين يجب أن يساوي مجموع الدائن.

## دورة المستند المالي

`Draft -> Posted -> Cancelled`

لا يسمح بتعديل القيد بعد Posted. عند الحاجة للتصحيح يتم إنشاء قيد عكسي أو مستند تصحيحي مع الاحتفاظ بالأثر التدقيقي.

## السندات

- سند قبض: يثبت استلام النقد أو ما يعادله مقابل حساب أو طرف آخر.
- سند صرف: يثبت دفع النقد أو ما يعادله.
- سند تحويل: ينقل قيمة بين حسابين ماليين دون تغيير إجمالي أصول المنشأة.

## الدقة

تستخدم القيم المالية بوحدة عشرية دقيقة وليس floating point. يجب منع القيود غير المتوازنة على مستوى قاعدة البيانات والخدمة.
