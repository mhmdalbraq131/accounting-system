# نظام المحاسبة

نظام محاسبي مستقل، عربي RTL، مخصص للعمل على الحاسب حاليًا مع بنية API قابلة للتوسع والربط المستقبلي مع أنظمة أخرى مثل MASARI.

## الحالة

مرحلة تأسيس المشروع.

## المبادئ

- Double-entry accounting
- PostgreSQL
- Backend/API مستقل
- واجهة عربية RTL
- سجل تدقيق للعمليات
- عدم حذف القيود المالية المرحلة حذفًا فعليًا
- قابلية التوسع للعمل عبر الشبكة والخادم لاحقًا

## البنية المستهدفة

```text
frontend/   واجهة المستخدم
backend/    API والنواة المحاسبية
infra/      Docker والبنية التشغيلية
docs/       التوثيق وقواعد المحاسبة
tests/      الاختبارات
```

## ملاحظة

هذا المشروع مستقل عن MASARI في هذه المرحلة. سيتم تصميم API يسمح بالتكامل معه مستقبلًا دون إعادة بناء النواة المحاسبية.
