# نظام المحاسبة

نظام محاسبي مستقل، عربي RTL، مخصص لوكالة الحج والعمرة والسفر، مع بنية API قابلة للتوسع والربط مستقبلًا مع MASARI.

## الحالة

النظام يحتوي على نواة محاسبية مزدوجة القيد، دليل حسابات، أطراف، سندات، مصروفات، قيود يومية يدوية، أبعاد محاسبية، فترات مالية، سجل تدقيق، تقارير مالية، إدارة فروع وصلاحيات، وواجهة عربية RTL.

## التشغيل

### 1. قاعدة البيانات

شغّل PostgreSQL عبر Docker:

```bash
docker compose up -d db
```

### 2. إعداد البيئة

انسخ `.env.example` إلى `.env` وعدّل `DATABASE_URL` و`SECRET_KEY`.

ولتهيئة حساب المدير استخدم:

```text
ACCOUNTING_ADMIN_USER=admin
ACCOUNTING_ADMIN_PASSWORD=ضع_كلمة_مرور_قوية_هنا
```

### 3. تشغيل الـ Backend

من مجلد `backend`:

```bash
python -m venv .venv
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1
pip install -e .
alembic upgrade head
python -m app.db.seed
uvicorn app.main:app --reload --port 8000
```

### 4. تشغيل الواجهة

من مجلد `frontend`:

```bash
npm ci
npm run dev
```

ثم افتح `http://localhost:5173`.

## المحاسبة

- القيود المرحّلة لا يتم تعديلها أو حذفها مباشرة.
- إلغاء القيد أو السند أو المصروف المرحّل يتم بعكس محاسبي.
- عند إنشاء فترات محاسبية، يمنع النظام الترحيل خارج فترة مفتوحة.
- الأبعاد المحاسبية يمكن ربطها بسطور القيود والمصروفات.
- يمكن استخدام نوع حساب `cost_of_service` لتصنيف تكلفة الخدمات، مع دعم الحسابات القديمة من نوع `expense` عند ربطها بإعدادات التكلفة.
- التقارير المالية تعتمد على القيود المرحّلة، وليس على مجرد السجلات التشغيلية.

## البنية

```text
frontend/   واجهة React + TypeScript عربية RTL
backend/    FastAPI + SQLAlchemy + Alembic
infra/      Docker والبنية التشغيلية
docs/       التوثيق وقواعد المحاسبة
```


## وحدات المحاسبة التشغيلية المضافة
- الذمم المدينة والدائنة: فواتير مبيعات ومشتريات، تواريخ استحقاق، أرصدة متبقية، أعمار الذمم.
- المدفوعات: قبض، صرف، تحويل داخلي، مع الترحيل والعكس.
- تخصيص المدفوعات على الفواتير والتحقق من الطرف والرصيد.
- الأبعاد المحاسبية ومراكز التكلفة والفترات المحاسبية وسجل التدقيق.
- القيود اليومية اليدوية والمصروفات مع دورة مسودة/ترحيل/إلغاء.
